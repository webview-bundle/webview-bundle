## Default Permission

Default permissions for the WebView Bundle plugin. Grants access to all of the source, remote, and
updater commands. To restrict access, replace this set with the individual `allow-*` permissions you
need (see `autogenerated/reference.md`).

#### This default permission set includes the following:

- `allow-source-list-bundles`
- `allow-source-list-builtin-bundles`
- `allow-source-list-remote-bundles`
- `allow-source-get-version`
- `allow-source-get-remote-staged-version`
- `allow-source-get-remote-previous-version`
- `allow-source-get-builtin-version-data`
- `allow-source-get-remote-version-data`
- `allow-source-update-remote-version`
- `allow-source-update-remote-versions`
- `allow-source-stage-remote-bundle`
- `allow-source-stage-remote-bundles`
- `allow-source-remove-remote-bundle`
- `allow-source-remove-remote-bundles`
- `allow-source-prune-remote-bundle`
- `allow-source-prune-remote-bundles`
- `allow-source-resolve-filepath`
- `allow-source-get-builtin-bundle-filepath`
- `allow-source-get-remote-bundle-filepath`
- `allow-source-unload`
- `allow-remote-get-update`
- `allow-remote-download`
- `allow-updater-get-update`
- `allow-updater-download`
- `allow-updater-install`
- `allow-updater-rollback`
