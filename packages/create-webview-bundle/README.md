# create-webview-bundle

An alias for [`create-wvb`](https://www.npmjs.com/package/create-wvb). Both scaffold the same
[Webview Bundle](https://wvb.dev) app — use whichever name you prefer:

```sh
npm create webview-bundle@latest
npm create wvb@latest
```

All logic, templates, and documentation live in `create-wvb`. See its
[README](https://github.com/webview-bundle/webview-bundle/tree/main/packages/create) for options.
