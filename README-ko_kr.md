웹뷰 번들은 웹뷰 기반 프레임워크 및 플랫폼을 위한 "오프라인 우선(Offline First)" 방식의 웹 리소스 배포 시스템입니다.

웹 애플리케이션 코드를 네트워크를 통해 불러와 웹뷰에 렌더하는 대신,
웹뷰 번들 파일(`.wvb`)로 패킹한 웹 애플리케이션 코드를 로컬에서 불러와 웹뷰에 렌더합니다.
또한, 리모트를 구성해 원격으로 웹뷰 번들을 다운받아 최신상태의 애플리케이션 코드를 네이티브 업데이트 없이 효과적으로 제공할 수 있습니다.

웹뷰 번들은 웹뷰가 제공되는 [Electron](https://www.electronjs.org/), [Tauri](https://tauri.app), Android, iOS, 그리고 [Deno Desktop](https://deno.com/desktop)(실험적)을
모두 지원하며, 웹뷰와 통신할 수 있는 브릿지 또한 제공됩니다.

자세한 내용은 [문서](https://wvb.dev/docs)를 확인해주세요.
